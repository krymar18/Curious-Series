Mastering AI in Excel

Use Copilot as an agent inside a live workbook: flatten a nested report, add calculated columns, build pivots, then compress the whole process into one prompt and a reusable script.

Start Part 1 Before You Begin

Before You Begin

Before we begin, here are a few tips for using Copilot in Excel:

  • Save your file as an .xlsx before you start.
  • Refer to columns by their data names rather than cell letters. For example, say "apply conditional formatting to the Total Impressions column" instead of "apply conditional formatting to column E." This gives Copilot the context it needs and makes the prompt easier to reuse across different files.
  • When using AI on a work document, save a backup copy first in case the AI changes or disrupts the data.

In this lab, we will use Copilot as an agent. Instead of asking questions about the data, we will have it generate formulas and scripts that transform the file through Excel. Because we are using AI to control Excel rather than analyze the data directly, many restrictions on using AI with certain data will not apply, giving us more freedom.

Quick note on privacy

One benefit of using Copilot in Excel is that it works within the workbook, so the data stays in the file and is not shared with other apps, including Copilot Chat. This helps keep the data contained while still allowing us to use AI safely.

Part 1

Flatten the Report

Getting one row per spot out of a nested avail.

Why does formatting matter?

Many Excel exports we use every day include merged cells, sub headers, and multiple header rows. These can make the report easier to scan visually, but they make Excel's built-in filtering, pivoting, and analysis tools much harder to use.

Flattening the data turns it into a consistent Excel table, which makes it easier to (with or without AI):

  • Filter data
  • Build pivot tables
  • Create charts
  • Apply formulas across rows
  • Navigate Excel faster

The lab prompts are designed to give Copilot for Excel a clear sense of the end goal, so the AI can ask clarifying questions and adapt the steps to your specific file. The hope is that you can reuse this prompt across most report formats, with Copilot guiding you through any questions specific to the use case.

Prompt to use

"This sheet is an order schedule. I want to analyze it using Excel's built-in tools, so I need it reformatted as a proper table first, flattened. Take a look, tell me the best way to do it, and ask me anything that's unclear before you start."

Prompt digest

Role, context, task, and format — broken down.

Role

No persona assigned. Copilot works directly as an Excel agent, not a role-played expert.

Context

"This sheet is an order schedule." Naming the file type anchors Copilot to the real data instead of a generic table.

Task

Reformat into a flattened table, and recommend the best way to do it before acting.

Format

Open. The only fixed rule is to ask first if anything is unclear.

Part 2

Add Calculated Columns

What does each line cost, and cost to reach someone?

Excel exports often include fixed calculated values, which can make analysis harder. AI can help convert those static calculations into Excel formulas, add new formulas, and apply calculations or transformations that make the analysis faster and more useful.

For open-ended analysis, AI can also help you brainstorm useful formulas and identify calculations worth testing first. Use the prompt below to start exploring what might be interesting in our sample avail.

Prompt 1

"Look at this table and suggest a few formulas that would help me understand cost and performance here. What would you add first, and why?"

Prompt digest

Role, context, task, and format — broken down.

Role

None assigned. Still working directly on the table, not through a persona.

Context

"This table." Builds on the flattened output from Part 1, so nothing needs re-explaining.

Task

Suggest formulas for cost and performance, then name which one to try first.

Format

Open. A short list with reasoning attached, not one fixed answer.

Strategies used
Contextual prompting Open-ended prompting

In this case, AI saves time on Excel formula syntax, applies multiple formulas at once, and helps create more complex formulas that may not be worth building manually. For example, we can transform the daypart column into three separate fields: days in M-Su format, start time, and end time, with the time fields formatted for easier filtering.

Prompt 2

"Good, add those directly to the table. Build three or four of them at once."

A direct follow-up in the same thread: it names an exact quantity and skips back to Prompt 1's suggestions instead of restating the task.

Reflection questions
  • How can we verify that the transformations and formulas are working correctly?
  • What are the main risks of using Copilot to generate formulas this way?
  • Major file transformations can take Copilot much longer than simple text responses. How can we account for that inefficiency, and is AI still worth using for this task?
Part 3

Build a Pivot

Once we have finished analyzing the raw table and added any needed calculations, it is time to use one of Excel's most powerful tools: pivot tables. Pivots let us group data by specific values and calculate sums, averages, counts, and other summaries for each group. Built-in filters and slicers also make it easier to explore the data. AI's real advantage is that it can generate multiple pivot tables at once, letting you spend more time analyzing the results instead of building the tables.

Start by asking Copilot to brainstorm pivot tables that could be useful for this dataset.

Prompt 1

"Look at this table and suggest a pivot table that would show where the budget is going. What would you set up, and why?"

Part 4

One Big Prompt

When working with a new format or analyzing data for the first time, it is usually best to start with smaller steps. This helps limit unintended actions by the AI agent. However, using Copilot one step at a time can become inefficient if we do it every time, making it less likely that we save meaningful time or effort on analytical tasks. I think of the first pass as teaching AI the workflow and deciding what the technical process should be. Once that is clear, we can ask Copilot to turn the process into one large, multistep prompt that takes us from the starting point to the final output, so we can move directly into analysis. Copilot will still need time to complete the steps, but having everything combined lets you switch to another task, check email, or respond to pending Slacks, then return to completed calculations and summary tables.

After testing the larger prompt, save it to your prompt library so it is easier to reuse later.

Prompt to use

"Combine everything we just did (flatten, the cost columns, the pivot, and the table conversion) into one prompt."

None assigned.

Context

Everything already done in this thread: the flatten, the cost columns, the pivot, and the table conversion.

Task

Combine all four prior steps into a single prompt.

Format

One prompt that reruns the whole chain end to end.

Strategies used

Part 5

Make It a Script

The all-in-one prompt from the previous step can speed up execution, but it still relies heavily on AI. That means it can take time, use up personal AI credits, and create opportunities for hallucinations or mistakes.

If the starting format is consistent, we can take the process further by using traditional automation for the full workflow. A script can run faster, produce more consistent results than AI, and be accessed directly in Excel or shared with the team.

Good thing, copilot can help us create that script.

Prompt to use

"Turn that same process into an Office Script I can run in the excel online."

Prompt digest

Role, context, task, and format — broken down.

Role

None assigned.

Context

The same combined process from Part 4, still in the same thread.

Task

Convert the process into an Office Script that runs in Excel Online.

Format

Runnable script code, not a text explanation.

Strategies used
Context expansion prompting Direct instruction prompting

Rule of thumb

A good rule of thumb: if your Excel file comes from a regular export, such as Power BI, AND Platform, or a similar system, the format is usually consistent enough to try automating the full process with a script.
