Before You Begin

Before we begin, here are a few tips for using Copilot in Excel:

  • Save your file as an .xlsx before you start.
  • Refer to columns by their data names rather than cell letters. For example, say "apply conditional formatting to the Total Impressions column" instead of "apply conditional formatting to column E." This gives Copilot the context it needs and makes the prompt easier to reuse across different files.
  • When using AI on a work document, save a backup copy first in case the AI changes or disrupts the data.

In this lab, we will use Copilot as an agent. Instead of asking questions about the data, we will have it generate formulas and scripts that transform the file through Excel. Because we are using AI to control Excel rather than analyze the data directly, many restrictions on using AI with certain data will not apply, giving us more freedom.

Quick note on privacy

One benefit of using Copilot in Excel is that it works within the workbook, so the data stays in the file and is not shared with other apps, including Copilot Chat. This helps keep the data contained while still allowing us to use AI safely.

Copilot in Excel has three modes: edit, plan, or chat, with edit as the default.

Edit (Allow editing)

Copilot works directly in the workbook. It's built for complex, multi-step tasks: reshaping data, merging sheets, building reports with multiple elements.

Plan

Copilot first builds a structured plan you review and confirm before anything runs. Use this when the task is big enough to ensure that the approach is correct before execution starts.

Chat only

Copilot analyzes workbook data and gives insights without making any changes. Good for one-off questions.

How to decide:
  • Task is well-defined and you trust the approach → Edit Fastest path.
  • Task is ambiguous, high-stakes, or touches a lot of the sheet (reordering columns across 20 tabs, restructuring a model) → Plan
  • You just want an answer, a formula explanation, or a data read → Chat only No risk of it touching anything.

Part 2

Create a Combined / Flattened Data Table

Why does formatting matter?

Many Excel exports we use every day include merged cells, sub headers, and multiple header rows. These can make the report easier to scan visually, but they make Excel's built-in filtering, pivoting, and analysis tools much harder to use.

Flattening the data turns it into a consistent Excel table, which makes it easier to (with or without AI):

  • Filter data
  • Build pivot tables
  • Create charts
  • Apply formulas across rows
  • Navigate Excel faster

One benefit of using Copilot is that it can handle multiple steps at once. While flattening the data, we can also ask it to add any missing calculated columns to save time.

Prompt to use

"Create a new sheet called “Combined” with a flattened table that pulls data from all 5 market sheets. Include these columns: Market, System, Network, Daypart, week date, units per week, rate, IMP, and a calculated column for total cost (rate × unit) and total IMP (IMP × unit). Each sheet can be structured differently, so you will have to look at the contents, as the row/columns will not always be consistent"

Part 3

Create Summary Roll-Up Tables

Objective

After creating the raw table with all WIPs and any required calculated columns, the next step is to build the roll-up. There are two main approaches. By default, Excel may try to generate formulas for each cell in the roll-up table. This can work, but it is slow because Copilot adds the formulas one at a time, and Excel recalculates the workbook after each new formula. With a larger dataset, this can cause Excel to freeze and make the prompt take much longer to finish. In testing, execution took at least 20 minutes. We recommend avoiding this method unless the dataset is small or you are using it mainly as a learning exercise and are comfortable waiting.

PivotTable-based roll-up

Prompt to use

"I would like to create a pivot table which will allow me to view summaries across all Markets. I will care about seeing Markets, Systems and total Cost, units and total IMP (the last three will need to be values). I would then like to add in slicers that will help me see networks and dayparts if desired"

Part 4

Use One End-to-End Prompt to Complete the Workflow

Objective

Ask Copilot to pull together one comprehensive prompt based on the earlier steps, instead of writing the full end-to-end prompt yourself.

Prompt to use

"Review the steps above in this training lab and create one end-to-end prompt that I can paste into Copilot in Excel. The prompt should tell Copilot how to complete the full workflow from start to finish. The prompt should include clear step-by-step instructions for renaming sheets, creating a Combined sheet, flattening the data, building the PivotTables, adding slicers, and validating the final output. Make the prompt specific enough that Copilot can act on it, but not so rigid that it fails if column names or sheet layouts vary slightly. Include instructions for Copilot to stop and ask me when something is missing, duplicated, unclear, or inconsistent. At the end, include a short checklist I can use to confirm that the generated prompt covers every required step."

The full workflow already covered in this lab — renaming, combining, roll-up, and slicers.

Task

A ready-to-paste prompt, followed by a short checklist.
