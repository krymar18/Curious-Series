Copilot in Excel

A practical reference for all three Copilot modes in Excel — Chat for exploration, Agent Mode for direct editing, and Analyst for advanced analysis — including what to verify before you trust the output.

Objective

Know which of the three Excel Copilot modes to reach for, understand what validation is required before you act on any AI-generated output, and build the habit of reviewing before forwarding.

Key idea

Agent Mode can fill a workbook with formulas that look correct and produce plausible numbers. The skill is not using Copilot — it’s knowing how to verify what it built. ‘Copilot said so’ is not a sufficient citation for a business recommendation.

Format your data as a Table first

Before opening Copilot in Excel, format your data as a Table (select the range → Ctrl+T) and add descriptive column headers — ‘Revenue_Q4’ not ‘Column D’, ‘Client_Name’ not ‘A’. These two steps produce measurably better Copilot output across all three modes. This is not optional good practice — it is a prerequisite for reliable results.

Features

Three modes — Chat (read-only), Agent Mode (read-write), and Analyst (Python-powered). Each behaves differently and has a different reliability profile.

Chat Mode — Questions, Formulas & Explanations

Read-only mode. Copilot answers in the pane; you apply changes manually. The most reliable category and the right starting point.

Plain-Language Data Analysis M365 Copilot
Excellent at
  • Quick insight questions on well-structured tables: top categories, outliers, trends
  • Cross-checking your own read of the data against AI
  • Data quality checks: blanks, duplicates, formatting inconsistencies
Better avoided for
  • Subtle statistical patterns — use Analyst mode for serious quantitative analysis
  • Subjective trend interpretation — Copilot describes obvious trends but may miss non-obvious ones
  • Unstructured or poorly named data — format as a Table with descriptive headers first
Data analysis prompt

Analyse this data and tell me: which category has the highest average sales this quarter, which month showed the biggest drop compared to the prior month, and are there any outliers in the Revenue column I should investigate? Summarise in plain language.

Formula Generation & Explanation M365 Copilot
Excellent at
  • Generating starting-point formulas for logic you can describe in plain language
  • Explaining inherited formulas from someone else’s workbook step by step
  • Generating error-handling wrappers around formulas you already know
Better avoided for
  • Financial models, compliance reports, or any calculation where accuracy is non-negotiable — always manually trace the logic
  • Edge cases: blanks, zero-division, date format mismatches — test on a sample before applying to the full dataset
  • Using a generated formula you cannot explain to a colleague — if you can’t explain it, don’t use it in a shared workbook

Agent Mode — Direct Workbook Editing

Agent Mode (GA April 2026) directly modifies your workbook. Always plan-first: Copilot proposes a step-by-step plan, you review and approve, then it executes. Format your data as a Table (Ctrl+T) with descriptive headers before starting.

Data Cleaning M365 Copilot
Excellent at
  • Removing duplicates, standardising text values, fixing date formats in a single instruction
  • Forward-filling blanks based on the value above
  • Splitting columns like Full Name into First and Last Name
Better avoided for
  • Ambiguous instructions — name the exact column and list the specific variants to standardise
  • Running on a workbook you haven’t backed up — always save a copy first; some operations cannot be undone through Ctrl+Z
  • Flagging complex logical inconsistencies — works for simple calculation checks, not multi-condition logic
Data cleaning instruction

Clean this table: remove duplicates based on [columns], standardise [column] to only these values: [list values], and flag in yellow any rows missing a value in [required column]. Show your plan before executing.

PivotTables, Charts & Multi-Step Operations M365 Copilot
Excellent at
  • Building a PivotTable and chart from a plain-language description in one instruction
  • Creating a summary sheet that pulls top results from multiple regional tabs
  • Adding calculated columns with a clear description of the logic
Better avoided for
  • Complex plans with many dependent steps — review the plan carefully; each step can introduce errors that compound
  • Charts where the data range is ambiguous — verify data source and axis labels after generation
  • Workbooks shared with others — Agent Mode modifies directly; establish who has authority to run it on shared files

Exercise — Agent Mode: Build an Analysis in Steps
  1. Open any Excel workbook with a table of at least 50 rows and 5+ columns. Format it as a Table (Ctrl+T) with descriptive column headers.
  2. Open Copilot from the ribbon and switch to Edit mode.
  3. Give Agent Mode a three-part instruction: clean the data (remove duplicates, standardise one column), add a calculated column, build a summary chart.
  4. Review the plan Copilot proposes before approving. Does it match your intent?
  5. After execution, verify every output: are formula calculations correct? Does the chart use the right data?
  6. Reflection: Where did Agent Mode save the most time? Where did it need correction?

Ampersand Spotlight — Using This Responsibly

Agent Mode can modify your workbook directly. The speed and polish of AI-generated analysis creates a legitimacy impression the underlying work may not support.

Verify before you present

Any Copilot-generated analysis presented to a decision-maker should be verified by the person presenting it: check formula logic on at least a sample of rows, verify the right data was used, and confirm the conclusions actually follow from the data. ‘Copilot said so’ is not a citation.

If you can’t explain it, don’t use it

If you cannot explain how a Copilot-generated formula works to a colleague in plain language, do not use it in a shared workbook. Use the formula explanation feature to learn how it works — or ask for a simpler formula you can explain.

Always work on a copy

Before running any Agent Mode operation on a workbook you depend on, save a backup. Some cleaning operations cannot be undone through Ctrl+Z. The tracked-change model in Excel does not work the same way as Word.

Shared workbooks need shared rules

In a shared workbook — a team tracker, a financial model, a client report template — an Agent Mode operation by one user can alter data others depend on. Establish which workbooks are protected from direct Copilot modification before enabling it for a team.

Conclusion & Reflections

Take a moment to reflect — it’s what makes the learning stick.

Key Takeaways
  • Always format data as a Table with descriptive headers before opening Copilot — output quality depends on it.
  • Chat mode is read-only and solid. Use it for exploration, formula generation, and formula explanation.
  • Agent Mode is read-write. Always review the plan before approving. Verify every output cell and chart after execution.
  • Formula validation is mandatory. Copilot-generated formulas can look correct while calculating incorrectly on edge cases.
  • If you can’t explain a formula to a colleague, don’t use it in a shared workbook.
Reflection
  • Think about the Excel work you do most. Which part costs the most time: building formulas, cleaning data, creating charts, or interpreting results? Which is Copilot best equipped to handle reliably?
  • Agent Mode’s plan-review-execute pattern requires you to evaluate the plan before approving. If you can’t evaluate whether a step is correct, can you use the feature responsibly?
  • A Copilot analysis says revenue dropped 12% in Q3. Before you present that, what do you verify — and how?
