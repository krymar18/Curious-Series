Write an Excel Formula from Plain Language

Describe a formula you need in plain English and get working Excel syntax back — with an explanation you verify before using it on real data.

8 – 10 min Excel with Copilot, or Copilot Chat M365 Copilot Premium
1
Describe what you need
You
▶
Do this
Think of a calculation or lookup you perform manually or avoid because the formula feels complex. Describe it in one sentence — plain language, not Excel vocabulary.
2
Ask for the formula with explanation first
Excel · Copilot or Copilot Chat
▶
Do this
Open Copilot. Replace the brackets with your actual requirements:
Copy prompt

Write an Excel formula that [describe what it should do in plain language]. If [describe an edge case — e.g. the value is blank, the lookup fails, there are duplicate rows], the formula should [describe what it should return in that case]. Explain what each part of the formula does before giving it to me.

◉
Look for
Read the explanation first — before looking at the formula. Does the explanation match what you intended? If not, the formula is wrong. Rewrite the prompt rather than testing a formula you already know is incorrect.
3
Test on a known sample
Excel
▶
Do this
Enter the formula in Excel. Test it on 3–5 rows where you know the expected output. If the result does not match, paste the error and ask:
Debug prompt

The formula is returning [describe the wrong output or error message] when I expected [describe the correct output]. My data structure is: [describe columns and sample values]. What is wrong and how do I fix it?

⚑ Ethics

A formula that produces wrong results silently is more dangerous than one that errors visibly. "Copilot wrote it" is not a defence for incorrect calculations. Test every formula on a known sample before using it at scale.

Key Takeaways
  • Asking Copilot to explain the formula before giving it to you is not optional — it is how you catch a formula that is syntactically correct but logically wrong.
  • Test on a known sample before scaling. A formula that runs without errors can still produce wrong results on data it was not tested against.
  • Describe edge cases explicitly in your prompt. Formulas that do not handle edge cases work in demos and fail in production.
