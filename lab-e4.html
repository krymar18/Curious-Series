Lab E4 · Technical

Reformat a Document or Note Structure

Transform unstructured notes, bullet points, or a poorly formatted document into a defined structure — then verify nothing was dropped or changed in meaning.

10 – 12 min Copilot Chat or Word with Copilot M365 Copilot Premium
1
Choose your content and define the target structure
You
▶
Do this
Choose content that exists in the wrong format for its purpose — meeting notes that should be an SOP, a long email that should be a structured brief, bullet points that should be a formal report section. Write down the target structure before opening Copilot. The more specific your structure, the more accurate the output.
2
Run the reformatting prompt
Copilot Chat or Word · Copilot
▶
Do this
Open Copilot with the content. Replace the brackets with your defined target structure:
Prompt 1 — Reformat

Convert the following [describe source format] into [describe target format]. Target structure: [list the sections or columns exactly]. Keep all the original information — do not summarise or remove any content. If any content does not fit the target structure, flag it rather than dropping it silently.

◉
Look for
Compare the output to the source. Is the content in the right sections? Are there any items Copilot flagged as not fitting? Did anything move that should not have?
3
Verify completeness
Copilot Chat or Word · Copilot
▶
Do this
In the same thread, run the verification prompt:
Prompt 2 — Verify completeness

Compare the reformatted version to the original input. Is there any information in the original that does not appear in the reformatted version? List anything that was dropped, changed in meaning, or placed in a section where it does not belong.

4
Make any corrections manually
You
▶
Do this
Copilot handled the structure. You are responsible for the accuracy and completeness of the final document. Make any corrections needed before using or distributing the output.
Key Takeaways
  • Copilot produces what you describe, not what you meant. Define the target structure before asking — an imprecise description produces output that is internally consistent but wrong for your purpose.
  • Always ask Copilot to flag content it cannot fit rather than drop it silently. One missing item in a reformatted SOP can cause an operational error.
  • The verification prompt ("what was dropped or changed?") is not optional for any reformatting task where completeness matters. Run it every time.
