Clean a Messy Dataset

Take a real dataset with at least one known quality issue and clean it systematically — then verify the changes row-by-row before using the output.

10 – 12 min Excel with Copilot Agent Mode, or Copilot Chat M365 Copilot Premium
1
Choose your dataset
You
▶
Do this
Choose a dataset with at least one known data quality issue — inconsistent date formats, mixed capitalisation, duplicates, or blank fields that should not be blank. If it is sensitive: share only column headers and a description, ask Copilot to write cleaning code, and run it locally.
2
Run the cleaning prompt
Excel · Copilot or Copilot Chat
▶
Do this
Open Copilot with the dataset. Replace the brackets with your specific requirements:
Prompt 1 — Clean

Clean this dataset: (1) Remove exact duplicate rows. (2) Standardise [field name] to [format — e.g. DD/MM/YYYY, UPPERCASE, Title Case]. (3) Flag rows where [required field] is blank — do not delete them, mark them with "MISSING" in a new column. Return the cleaned data and a summary of exactly what was changed and how many rows were affected.

◉
Look for
Read the summary of changes first. "47 rows standardised, 3 flagged as blank" is useful. "The data was cleaned" is not — if that is all you get, ask for specifics before accepting the output.
3
Spot-check manually
You
▶
Do this
Pick 3–5 rows at random and compare the original to the cleaned version. If you find an error, fix just that type:
Prompt 2 — Targeted fix

Some rows were incorrectly transformed in [field]. Example of the wrong transformation: [describe]. The correct format should be [describe]. Fix only this issue and return the corrected rows with a count of how many were changed.

Key Takeaways
  • Always ask for a summary of what was changed and how many rows were affected. A summary without counts is not verifiable.
  • Spot-check manually after any cleaning operation. AI can silently mishandle edge cases that look fine in the summary.
  • For large or sensitive datasets: ask for the cleaning code and run it locally. Repeatable, auditable, and the data never leaves your environment.
