LLM Predicting vs. LLM Searching

This session explains what changes when an LLM is answering from training data versus actively searching, then ties it to how Copilot behaves across different Microsoft surfaces.

Predicting vs. searching

The document shows that the answer can look the same either way, but reliability depends on whether a tool ran first.

Aspect Predicting from training data Searching
What triggers itAny answer the model gives without a toolA web search, SharePoint index, or database query runs first
Knowledge cutoffHard cutoff, typically months behind the current dateNo cutoff; retrieves current information at query time
How current it isCould be years staleAs current as the search index allows
What “I found” meansI predicted this from patterns in training dataI retrieved this from a live source just now
Reliability on recent eventsLowHigh if the source is reliable
How to identify itNo citations, no source section, no visible search actionCitations, source URLs, or a visible search action

How to know which mode is active in Copilot

Practical implication

When you use Copilot in Word to write about a regulation, a competitor, or a recent industry development, it is generating from training data, not searching for current information. It may sound like it knows even when it does not.

Telling the difference mid-conversation

Signs it is predicting: no citations, no source section, no visible search action, immediate and fluent output.

Signs it is searching: a searching indicator, citations or source URLs, and a bit more latency.

If in doubt, ask whether the answer came from live search, your documents, or training data.

Copy prompt

For the answer you just gave me — did that come from a live search, from my documents, or from your training data? Be specific about each part.

Activity

Run a predict-versus-search challenge with the same set of questions in Copilot Chat, once with web search on and once with it off. For factual questions, the difference is often visible; for synthesis and drafting, it usually is not.
